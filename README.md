What I’m Learning
The exercises in this repository cover core C# concepts, arranged by topic:
• Variables and Types: Storing and working with different data types (int, string, double,
bool).
• Console I/O: Reading user input (Console.ReadLine) and printing results to the screen
(Console.WriteLine).
• Methods: Writing reusable pieces of code that accept input and return results.
• Conditions and Logic: Using if/else statements and logical operators to make decisions.
• Loops: Iterating through data using for, while, and foreach loops.
• Arrays: Working with fixed-size collections and manipulating elements using indexes.
• Sorting: Implementing algorithms to arrange values in an array.
• Lists: Managing dynamic collections using List<T>, adding/removing items, and using
Count.
• Searching: Finding specific values within collections.
I will update this list and add more exercises as I continue learning.
